# Student Record Management System in C

## About the Project

The Student Record Management System is a menu-driven C programming project that manages student records using structures, functions, arrays, and file handling.

## Features

* Add a student
* Display all student records
* Search for a student by roll number
* Update student marks
* Delete a student record
* Calculate percentage
* Calculate grades
* Display Pass/Fail status
* Save and load records using file handling

## Technologies Used

* C Programming
* Structures
* Arrays
* Functions
* Pointers
* File Handling

## How to Compile

```bash
gcc -Wall -Wextra -std=c11 main.c -o main
```

## How to Run

On Windows:

```powershell
.\main.exe
```

## Data Storage

Student records are stored in `students.txt`, allowing records to persist after the program exits.
